## Solution

```java
class Solution {
    public int[] replaceElements(int[] arr) {
        int j = -1;

        for (int i =arr.length -1; i>=0; i--){
           int temp =arr[i];
           arr[i]=j;
           j = Math.max(j,temp);
        }
        return arr;
    }
}
```
