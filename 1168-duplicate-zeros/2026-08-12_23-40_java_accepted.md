## Solution

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        int[] arr2=new int[arr.length];

        int i=0;
        int j=0;

        while(i < arr.length){
            if (arr[i] == 0){
                if (j < arr.length){
                    arr2[j]=0;
                }
                j+=1;
                if (j < arr.length){
                    arr2[j]=0;
                }
            }
            else {
                if (j < arr.length){
                   arr2[j] = arr[i];
                }    
            }
            i+=1;
            j+=1;
             }
            for(int q=0; q < arr.length; q++){
                 arr[q] = arr2[q];
        }
    }
}
```
